# Queue Core Bot

Telegram-бот для очередей на защиту лабораторных в чате группы. Вместо
переписки «я после Ани» — одна доска с кнопками, которую видят все.

```
[ В конец ]       [ Где я? ]
[ ✓ Сдано ]       [ ↩ Сброс ]
[     📋 Все очереди      ]
```

## Как пользоваться

Добавьте бота в чат группы и отправьте:

| Команда | Что делает |
|---|---|
| `/new <название>` | создать очередь |
| `/swap <позиция>` | поменяться местами с человеком на этой позиции |
| `/close <название>` | закрыть очередь |
| `/queues` | список открытых очередей: нажмите на очередь, чтобы показать её доску внизу чата |
| `/show <название>` | показать доску очереди внизу чата |

Кнопки действуют только на того, кто их нажал, а ответ видит только он.
«↩ Сброс» возвращает на прежнее место, если «✓ Сдано» нажали по ошибке.
Если бот — администратор, он закрепляет список очередей.
Обмен местами бот всегда объявляет в чате, так что никто не сдвинет другого
незаметно.

## Запустить своего бота

Нужен токен от [@BotFather](https://t.me/BotFather) и Docker:

```bash
git clone https://github.com/Silvelle/queue-core-bot.git
cd queue-core-bot
cp .env.example .env    # впишите токен
docker compose up -d --build
```

Очереди хранятся в SQLite и не теряются при перезапуске.

Написан на Go. Код и тесты — в [`internal/`](internal).
