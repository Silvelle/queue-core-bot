# Queue Core Bot

Telegram-бот для очередей на защиту лабораторных в чате группы. Вместо
переписки «я после Ани» — одна доска с кнопками, которую видят все.

## Как пользоваться

Добавьте бота в чат группы и отправьте:

| Команда | Что делает |
|---|---|
| `/new <название>` | создать очередь |
| `/swap <позиция>` | поменяться местами с человеком на этой позиции |
| `/swap <кто> <с кем>` | поменять местами двух человек: `/swap 1 3`, по номерам или ID |
| `/add <ID или @имя> <*место>` | добавить человека в очередь, без места — в конец. Можно ответить командой `/add` на его сообщение |
| `/place <номер, ID или @имя> <*место>` | переставить человека: `/place 7 3` переставит №7 на №3, без места — в конец |
| `/delete <номер, ID или @имя>` | убрать человека из очереди |
| `/close <название>` | закрыть очередь |
| `/queues` | список открытых очередей: нажмите на очередь, чтобы показать её доску внизу чата |
| `/show <название>` | показать доску очереди внизу чата |

Кнопки действуют только на того, кто их нажал, а ответ видит только он.
После защиты нажмите «Выйти». Если кто-то вышел по ошибке, `/add` вернёт его, а
`/place` переставит на нужное место.
В группе с темами бот отвечает в той же теме, и у каждой темы свои очереди.
Обмен местами, перестановку и удаление бот всегда объявляет в чате, так что
никто не сдвинет и не уберёт другого незаметно.

## Запустить бота

Нужен токен от [@BotFather](https://t.me/BotFather) и Docker:

```bash
git clone https://github.com/Silvelle/queue-core-bot.git
cd queue-core-bot
cp .env.example .env    # впишите токен
docker compose up -d --build
```

Очереди хранятся в SQLite и не теряются при перезапуске.

Написан на Go. Код и тесты — в [`internal/`](internal).
